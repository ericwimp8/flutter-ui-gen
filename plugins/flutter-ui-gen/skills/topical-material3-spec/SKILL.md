# Topical Material 3 Spec

## File Index

Each file covers a Material 3 reference concern. Format: What it is / When to
use it.

- [Material 3 Spec Index](references/material3-index.md) - Complete page map for the Material 3 specification / When locating exact Material 3 guidance by component, foundation, style, accessibility, layout, motion, or visual example.
  - Locate component guidance - when the task names or implies a Material 3 component such as buttons, cards, dialogs, navigation, lists, menus, text fields, or tooltips.
  - Locate foundation guidance - when the task concerns adaptive design, accessibility, interaction, layout, content design, or design tokens.
  - Locate style guidance - when the task concerns color, elevation, icons, motion, shape, state layers, or typography.
  - Find visual examples - when the task needs screenshots, diagrams, or animation examples from a page's `assets/` folder.
  - Check animation examples - when a page lists WebP contact sheets for motion or interaction examples.

## Usage

This index contains Material 3 specification references. When answering or
implementing any Material 3 problem listed above, read the matching spec page
first instead of relying on general knowledge.

**Before writing:** Scan the file index. If the task matches an entry, open
[Material 3 Spec Index](references/material3-index.md), choose the relevant
page, and read the linked `page.md`.
**While writing:** If the work depends on Material 3 behavior, layout, motion,
accessibility, or styling details, use the matching page and its nearby
`assets/` folder as the reference.
**After writing:** Verify the answer or implementation matches the relevant
Material 3 page and any visual examples needed for the task.
