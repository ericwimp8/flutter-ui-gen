# Flutter UI Gen

Codex plugin marketplace package for Flutter UI generation support, including Material 3 references and theme generation tooling.

## Install

Add the marketplace:

```bash
codex plugin marketplace add ericwimp8/flutter-ui-gen
```

Then install `Flutter UI Gen` from `/plugins` in Codex.

## Package Contents

This repository publishes only the Codex plugin package:

- `.agents/plugins/marketplace.json`
- `plugins/flutter-ui-gen/`
